# rogue-glab-skill

**Rogue Development** skill package for agents.

GitLab CLI for merge requests, issues, pipelines, and CI/CD. Use when the project needs this capability or the user / team manifest asks for it. Use for specialized `glab` work when listed in TEAM.yaml or explicitly requested.

- Asset Store: https://rogue-dev-studio.github.io/rogue-asset-store/
- Skill id: `glab`

## Install

Copy `SKILL.md` into your agent skills directory (Cursor / Claude Code / compatible host), or clone this repository.
